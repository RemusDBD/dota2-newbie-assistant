# 技能加点、英雄克制与关键技能应对

这份参考用于把“知道技能”转成新手能在本局执行的操作。优先回答当前最有价值的选择，不追求覆盖所有英雄或列出固定的 1～25 级模板。

## 技能加点输出契约

完整攻略至少给出：

1. **一级技能**：明确一级点什么，以及它解决补刀、换血、保命或抢符中的哪个问题。
2. **前四级顺序**：使用 `1级 A → 2级 B → 3级 A → 4级 C` 的可照抄格式；若分支未知，给两种分支都安全的主线。
3. **主副加点**：说明主什么、副什么、哪个技能前期只取一级，以及原因。
4. **大招与天赋方向**：不要机械写“有大点大”。明确本局何时点大；天赋优先写生存、控制、刷钱或输出方向，只有确认当前版本文本后才写精确数值。
5. **一条动态调整**：例如“被持续压血时，提前补一级保命技能”“完全无压力时，提前强化刷钱技能”。

极速模式压缩成一行：`加点：一级 A；前4级 A-B-A-C；主 A 副 B，被压时提前补 C。`

## 怎样选择加点

按下面的顺序判断，不要先套通用攻略：

1. 一级技能能否保证第一波兵、避免被击杀，或创造明确击杀机会。
2. 本路最缺的是补刀、消耗、续航、逃生还是控制。
3. 英雄在第一件核心装备前主要靠技能作战，还是需要尽快提高刷钱速度。
4. 敌人的关键强势等级和技能冷却是否要求提前加保命、控制或射程。
5. 己方辅助能否提供稳定先手、减速、治疗或爆发，从而改变主副加点。

每个推荐都要能回答“为什么这局这样点”。不要只给技能序号，也不要凭旧版本记忆写完整 1～25 级序列。

命石、先天技能或天赋分支会改变加点时：

- 极速模式：给共同安全主线，并提醒确认分支后微调。
- 完整模式：写清采用的命石/分支；若用户没有提供，只给最关键的二选一差异。
- 精确技能文本、伤害类型、驱散、控制免疫和数值没有当前版本依据时，不做绝对断言。

## 克制分析卡

只选择对本英雄和位置影响最大的 2～3 名敌人。每名敌人按以下顺序回答：

- **克制原因**：具体到射程、持续追击、爆发、控制链、反先手、削属性、幻象或切后排，不只写“克制你”。
- **危险预兆**：玩家在屏幕上能看到或听到什么，例如抬手、跳刀进场、特效、站位变化或某个前置技能。
- **怎么躲**：提前站哪里、与队友保持多远、等哪个技能后再进、向哪个方向移动，或用什么可靠机制规避。
- **躲不开怎么减伤**：补血、属性、抗性、护盾、驱散、控制免疫、位移、救人装或队友技能；只推荐确认适用的机制。
- **反打窗口**：对方关键技能空掉、持续状态结束、位移用过或与队友脱节后的具体动作。

“英雄克制”默认是本局机制判断。没有查询对应样本时，不要把它写成统计胜率结论。

## 常见技能与大招的应对框架

先识别技能类型，再给动作。不要看到“大招”就统一推荐黑皇杖。

- **指向性单体技能**：保持施法距离外、利用视野和队友挡位置；林肯法球、莲花宝珠或黑皇杖仅在确认交互适用时推荐。
- **飞行弹道**：说明能否通过位移、隐身、进入战争迷雾或无敌帧躲避；不是所有弹道都能用同一种方法躲。
- **地面范围技能**：提前分散，避免站在狭窄地形；看到前摇后向范围外最短路径移动，不在圈内犹豫输出。
- **跳刀先手与范围控制**：核心是视野、间距和站位层次。让前排先露视野，后排与另一名核心不要重叠。
- **持续施法**：开打前确认己方谁保留眩晕、沉默或位移打断；不要让所有控制先交在前排身上。
- **延迟标记或负面状态**：只有确认当前版本可驱散时才写驱散方案；否则优先给拉开距离、回血、护盾和救人时机。
- **无法可靠躲避的全局或瞬发伤害**：直说“重点不是躲”，改为提前保持血量、分散承伤、开减伤或留救人技能。
- **变身、领域或长持续大招**：先拉开、风筝并计算持续时间，不在对方最强的十几秒里硬拼。
- **随单位数量放大的范围伤害**：英雄、幻象和召唤物分散，不把额外单位带到队友身边。

## 新手可重复执行的对战技巧

技巧必须能从屏幕上观察并能立刻照做。优先选择以下内容：

- **仇恨拉兵**：在安全距离对敌方英雄发出攻击指令，把近战兵拉向自己，改善补刀位置；不要为拉兵走进敌方双人攻击范围。
- **冷却窗口换血**：等对方关键控制或爆发打在兵上、空掉或进入冷却，再上前补刀或换血。
- **用兵线保护自己**：对依赖非指向技能的对手，隔着兵线站；对范围消耗强的对手，避免与整波兵重叠。
- **先看动作再按保命装**：跳刀、抬手、音效或前置减速往往比伤害数字更早出现；把保命装备放在固定顺手键位。
- **高地与战争迷雾**：没有视野时不要第一个走上坡；让召唤物、幻象、肉盾或侦察技能先探。
- **分层站位**：前排露视野，主输出在其后一个技能距离，救人辅助再后半个身位，避免一次范围控制命中多人。
- **利用关键技能空档**：敌人大招或先手交空后，立即报信并争取推塔、肉山或强开，而不是继续无目的刷钱。

每局最多给 1～2 个与当前英雄直接相关、可以反复执行的技巧。避免“注意走位”“小心大招”这类没有动作的句子。

## 可靠性检查

输出前快速检查：

- 是否给了一级和前四级加点，而不只是“主一副二”。
- 是否解释了本路为什么难打或好打。
- 是否选出了最危险的技能，而不是平均讲完五名敌人。
- “躲法”是否真实可执行；不能躲的技能是否改成减伤、站位或救援方案。
- 是否给了技能空掉后的反打窗口。
- 是否把未经查询的机制判断误写成数据结论。
- 是否对驱散、控制免疫、技能免疫、破坏和无敌交互作了未经当前版本核对的绝对承诺。
