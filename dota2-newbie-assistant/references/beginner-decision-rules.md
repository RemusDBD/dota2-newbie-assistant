# 新手决策规则

这些规则用于把阵容信息转成简单、可执行的建议，不替代当前版本数据。先判断玩家职责，再选装备；同一件装备不能因为“热门”就推荐给所有位置。

## 位置优先级

- **1号位**：稳定补刀与生存 → 刷钱效率/关键战斗装 → 活着持续输出。没有明确安全窗口，不建议过早跟无目标的团；团队没给刷钱区视野时，自己拿一个安全眼。
- **2号位**：等级与符点/支援节奏 → 第一件形成击杀或生存能力 → 控制中线并带动边路。准备主动找隐身英雄时，不能只等辅助带粉。
- **3号位**：不崩线 → 制造先手或承伤窗口 → 用团队装补阵容缺口。不要把自己当第二个纯刷核心；作为第一接触目标的人要能及时反隐。
- **4号位**：保证线不被毁 → 关键小件和游走时机 → 先手、反手或救人。离线前先确认核心能独立吃线。
- **5号位**：保核心补刀与兵线 → 视野、补给和低成本保命 → 团战先放出关键技能再死。不要为了憋大件长期不买真眼、雾和保命小件，但也不承担全队唯一的反隐责任。

## 对线扫描

依次回答：

1. 谁拥有远程消耗、爆发、回复、驱散、减速或硬控？
2. 对方的击杀通常由哪个技能起手？该技能空掉后有多长换血窗口？
3. 己方应该控线在塔前、推线抢等级，还是拉野改变兵线？
4. 本路主要资源是生命、魔法还是补刀属性？据此决定补给和第一个小件。
5. 双人路先找更脆、没有逃生或关键技能进入冷却的目标，不默认集火核心。

## 出门与小件

- 面对频繁施法的双人路，优先考虑魔棒体系；不能只因敌方有技能就机械购买。
- 会持续被点时保证足够回复和基础属性；不要为了早出大件省掉让自己能站线的小件。
- 近战补刀困难时优先解决护甲、移速、补刀或续航中的主要矛盾。
- 辅助先保证补给、视野和保命；核心先保证补刀与不被击杀。
- 鞋、魔棒、护腕/系带/挂件等小件是否升级，取决于它能否帮助撑过下一次关键时间点。

## 威胁到装备的映射

只从英雄职责能合理使用的选项里挑一两个：

- **大量魔法爆发或团控**：核心考虑黑皇杖；团队位考虑洞察烟斗、微光披风；需要驱散时再评估分身斧、风杖或莲花。不要把黑皇杖推荐给没有经济的五号位。
- **单点先手或必须挡的一次技能**：林肯法球；能反弹/驱散且适合团队位时考虑莲花。先分清是否会被廉价技能破掉。
- **沉默、缠绕、可驱散负面效果**：分身斧、风杖/风之杖、莲花、黑皇杖等按英雄与时机选择；说明它能解除什么。
- **高物理爆发或右键核心**：护甲、天堂之戟、幽魂权杖、赤红甲、强袭装甲等按位置选择；辅助优先低成本活下来放技能。
- **高回复或吸血**：魂之灵瓮、希瓦的守护、斯嘉蒂之眼等按英雄适配；同时提醒集火与控制比盲目减疗更重要。
- **幻象或召唤物**：范围清线装、雷锤体系、辉耀、希瓦或赤红甲按职责选择；先判断自己需要清幻象还是活过幻象的输出。
- **隐身**：粉、真眼、宝石是团队必需品；不要把反隐全部推给五号位。新手速报中明确说“出门/回城补粉”。
- **近战切后排、容易被贴脸**：推推棒、飓风长戟、风杖、幽魂权杖等；重点说明何时按，而非只报装备名。
- **闪避**：有持续物理输出职责的英雄再考虑金箍棒等命中方案；法系和辅助不为“克闪避”硬转物理装。
- **高机动或逃生**：优先稳定控制、沉默、视野和留技能顺序；不要把所有希望寄托在一件昂贵装备。

## 己方阵容缺口

- 缺先手：3/4号位提高跳刀、控制或接近手段的优先级；核心不要无条件承担第一个进场。
- 缺救人：辅助考虑微光、推推、莲花等，但一次只推荐最适配的一件。
- 缺推线：安排有安全清线能力的人处理危险线；装备只作为补充，不能要求无逃生辅助深带。
- 缺建筑伤害：赢团后明确转塔/肉山，不用继续追人；核心路线保留持续输出。
- 缺持续输出：控制位围绕己方主要输出保护，不要所有人同时先手后排。

## 前中后期动作

- **前期**：围绕兵线、等级和第一件小装；说清“什么时候能换血/击杀”和“什么时候只吃经验”。
- **中期**：围绕第一件核心装、关键大招和地图目标；给出“有技能跟团、没技能收安全线”的简单边界。
- **后期**：先确认买活、肉山、关键控制和视野；给一个明确站位参照，例如“站在先手位身后一个屏幕”。

## 新手过滤器

- 优先容错而非纸面最高输出。
- 同时拥有多个主动装备时，说明最先按哪一个；避免一次推荐四个保命主动装。
- 贪经济装必须说明不能打架的时间成本。
- 逆风优先能立刻发挥作用的组件和小件，不机械照搬顺风路线。
- 不说“稳住”“注意走位”这类空话；改成可观察的动作或触发条件。
