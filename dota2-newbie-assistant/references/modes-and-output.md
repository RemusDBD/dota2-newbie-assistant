# 输出模式

## 极速语音

目标：10秒左右听完核心建议。最多8行，每行只说一个动作，不使用表格。

固定顺序：

```text
7.41e｜我方英雄·位置，对线：敌方英雄
出门：核心消耗品与属性小件
一级：技能或一级打法；拿不准加点时只说打法
对线：最重要的补刀、换血或兵线动作
先买：第一个小件及原因
路线：第一大件 → 第二选择；给一个条件分支
团战：站位、先手或保护目标
别做：本局最容易导致崩线/暴毙的动作
```

要求：

- 用户没给完整阵容也直接回答。
- 不查询网络，不朗读来源网址。
- 不堆砌备选装备；每个阶段最多两个选择。
- 若技能加点可能随版本或分路变化，用“一级打法”代替武断加点。

## 截图或文字完整攻略

按以下结构输出：

1. `识别结果`：一行回显双方阵容、自己的位置和本路对手；不确定项加“？”。
2. `本局一句话`：本局赢法和最主要风险。
3. `出装路线`：出门、对线小件、核心一、核心二、后期；每个核心装说明原因。
4. `条件分支`：最多四条“如果……就……”；只保留与本局阵容相关的分支。
5. `对线期`：兵线、换血、击杀目标、视野/支援。
6. `中期`：刷钱与跟团边界、第一波强势期、地图区域。
7. `后期`：站位、先手目标、买活与关键技能交换。
8. `新手别犯`：三条具体错误。
9. `依据与版本`：版本号；哪些是阵容机制推断；若实际查询了数据，再列数据来源与时间。

不要输出看似完整但没有优先级的六神装清单。装备路线必须允许因局势改变。

## 局中求助

最多6行：

```text
结论：下一件买什么；若钱不够先补哪个组件
原因：它解决当前哪个敌人或威胁
接下来3分钟：刷哪类区域、跟哪位队友、避免什么区域
团战：等哪个技能后进，或先对谁做什么
改线条件：出现什么情况就换备选装备
需要补充：只有确实会改变答案时，问一个最短问题
```

如果用户正在交战或明确说“只要答案”，只给前四行。
