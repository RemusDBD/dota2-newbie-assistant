# Changelog

本文件记录 Dota 2 新手助手 Skill 的用户可见变化。Skill 版本与 Dota 2 游戏补丁号彼此独立。

## 0.8.0 - 2026-09-12

- 新增“新手运营与出装底层框架”：将用户提供的久远 Vortex 六份基础教学资料重新提炼为资源、时机、地图压力、团战与转化的统一决策方法。
- 新局指导可根据该框架解释兵线处理、打钱路线、游走条件、第一件关键装、领先/落后中期策略与四号位开局；不照抄资料中的固定数值、地图点位或版本化时间。
- 新增出装的“定义问题—装备改变行动—赶上窗口”筛选法，并将真视、粉、雾和保命装纳入“出题/解题”的实际决策。
- 感谢资料作者久远 Vortex 提供的教学启发；本 Skill 的原作者署名仍为 TimZhang踢木桩。

## 0.7.1 - 2026-09-06

- 在 Skill 元数据、正文和 ChatGPT 单文件知识包中增加原作者署名：TimZhang踢木桩。

## 0.7.0 - 2026-08-28

- 新增 ChatGPT Live 完全语音模式，首次导入后新局指导与赛后复盘均不要求键盘输入或粘贴链接。
- 比赛编号支持逐位口述、两组复读确认和语音纠错，确认后自动查询 OpenDota。
- 联网失败时改为语音说明与重试，不再把粘贴 OpenDota 链接作为兜底步骤。
- 新增单文件 ChatGPT 项目知识包构建脚本，合并版本、加点、出装、克制、视野、语音别名与复盘规则。
- Live 默认先播报 15～30 秒核心结论，按“详细说”或“展开某部分”继续补充。

## 0.6.0 - 2026-08-27

- 新增赛后数据复盘模式，与原有新局指导模式并列。
- 输入比赛 ID 和指定英雄名称即可复盘自己或其他玩家的该局英雄，不需要绑定 Steam 账号。
- 支持分析真实出装顺序、分钟经济/经验、正反补、团战记录、目标事件与关键转折；数据不完整时自动降级为基础结算复盘。
- 复盘按对线期、中期、后期、关键时间点、出装经济、胜负点和下局改进规则分层输出。
- 明确区分 OpenDota 数据事实与机制推断，不进行录像下载、视频播放或逐帧分析。
- 增加 Valve 简体中文英雄和物品名称缓存，比赛复盘可直接使用中文英雄名称。

## 0.5.0 - 2026-08-27

- 截图和文字阵容默认改为分层攻略，不再使用十条平铺式清单。
- 每个主题先给一行可快速扫读的极简结论，再用 1～3 条补充原因、动作和调整条件。
- 恢复加点、对线、出装、克制、视野和前中后期的必要细节，同时保留极速语音与交战中求助的短格式。
- 默认攻略采用清晰的小标题与留白，不使用表格或密集长段落。

## 0.4.0 - 2026-08-27

- 默认改为适合游戏中快速阅读的战局简报，截图和文字阵容不再自动输出长报告。
- 极速语音压缩到最多 8 行，局中求助压缩到最多 6 行。
- 每份攻略同时显示 Skill 版本与适用的 Dota 2 补丁版本。
- 建立小版本与 Changelog 维护规则。

## 0.3.0 - 2026-08-27

- 增加真假眼、显影之尘、血腥榴弹、诡计之雾和真视宝石的购买与使用建议。
- 增加对线、中期、后期眼位区域以及路人局视野兜底规则。

## 0.2.0 - 2026-08-27

- 增加技能加点、英雄克制、关键技能规避、减伤与反打窗口。
- 增加 OpenDota 技能、天赋和英雄技能映射缓存。

## 0.1.0 - 2026-08-27

- 建立基于中文语音、文字和阵容截图的新手本局助手。
- 支持出装路线、对线建议、前中后期行动以及版本与数据来源标注。
